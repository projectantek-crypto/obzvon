# Обзвон ЕГРЗ — как запустить

Страница живёт на GitHub Pages, статусы и заметки хранятся в Google Таблице.

## 1. Таблица и скрипт (10 минут)
1. Создайте пустую Google Таблицу, например «Обзвон ЕГРЗ — статусы».
2. Расширения → Apps Script. Удалите всё в редакторе, вставьте содержимое `apps-script.gs`.
3. В строке `const PASSWORD = '...'` придумайте пароль. Его будут вводить менеджеры.
4. Сохраните (иконка дискеты).
5. Развернуть → Новое развертывание → тип «Веб-приложение»:
   - Выполнять как: **Я**
   - У кого есть доступ: **Все**
   Нажмите «Развернуть», разрешите доступ к таблице (Google предупредит, что приложение не проверено: «Дополнительно» → «Перейти»).
6. Скопируйте URL веб-приложения (заканчивается на `/exec`).

Лист «Статусы» появится сам при первом изменении статуса.

## 2. Сайт на GitHub (10 минут)
1. github.com → New repository, например `obzvon`. Видимость: Public (для бесплатного GitHub Pages).
2. Откройте `config.js` в любом редакторе, вставьте URL из шага 1.6 между кавычками в `API_URL: ""`.
3. В репозитории: Add file → Upload files → перетащите `index.html`, `config.js`, `orgs.json`, `objects.json`, `robots.txt` → Commit changes.
   `apps-script.gs` и этот README загружать не нужно.
4. Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save.
5. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/obzvon/`.

Менеджер открывает ссылку, вводит своё имя и пароль из шага 1.3 — и работает.

## Если что-то поменяли
- Изменили код скрипта → Развернуть → Управление развертываниями → карандаш → Версия: «Новая версия» → Развернуть. URL при этом не меняется.
- Сменили пароль → то же самое; менеджеров попросит ввести новый пароль.
- Обновили базу компаний → замените `orgs.json` и `objects.json` в репозитории.

## Что важно знать
- Публичный репозиторий означает, что файлы базы (компании, телефоны, ЛПР) может скачать любой, кто найдёт ссылку. Поисковики сайт не индексируют (`robots.txt`). Статусы и заметки закрыты паролем — они в вашей таблице.
- Таблицу можно смотреть, фильтровать и выгружать как обычно. Не переименовывайте лист «Статусы» и не переставляйте колонки — страница их читает.
- Страница подтягивает изменения других менеджеров раз в 20 секунд.
